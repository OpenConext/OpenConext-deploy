Role Name
=========

This role is designed to configure a server to run the scripts from the surfconext-tool and sram-tools.
The role was created after the server had already been installed, so this role is a recreation of that.
In case you are using this role to install onto a new server make sure everything required is there, test the revelevant scripts etc.
